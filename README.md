## 🏆 What I Build

### 🛡️ ClickFortify — Multi-tenant SaaS for Click Fraud Detection

> A production-grade platform protecting ad campaigns across Google & Meta Ads with real-time bot detection, automated IP exclusion, and advanced analytics.

**Tech:** `NestJS` `Next.js` `MongoDB` `Redis` `Bull` `Docker` `Google Ads API` `Meta CAPI` `Stripe` `WebSockets`

**Architecture highlights:**
- 4 microservices (API, Tracker, Webhook, Worker)
- Real-time click tracking pixel with <50ms response
- Automated rules engine for fraud response
- Multi-tenant workspace isolation

### 🧩 Architecture Patterns I Use

| Pattern | Description |
|---------|-------------|
| **Microservices** | Event-driven communication between services |
| **CQRS** | Read/write optimization for high-throughput systems |
| **Queue-based Processing** | Async job processing with Bull/Redis |
| **Multi-tenancy** | Workspace-level data isolation |
| **Domain-Driven Design** | Complex business logic modeled around domains |
| **CI/CD** | Automated pipelines with Docker & GitHub Actions |
